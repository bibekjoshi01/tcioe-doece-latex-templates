\section{IMPLEMENTATION}

This section documents the implementation work completed to date, building on the architecture and design described in Section~4. Consistent with the current stage of the project, implementation effort has focused on reproducing established baseline and state-of-the-art (SOTA) detectors on clean benchmark audio; integration of the RTC-aware transmission pipeline (Sections~4.1--4.4) with the detection models is planned for the final implementation phase. The section is organized as a build narrative: the dataset and protocol used for training and comparison, the baseline models implemented so far, and the evaluation discipline followed throughout.
