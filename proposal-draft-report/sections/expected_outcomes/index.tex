\section{EXPECTED OUTCOMES}

The proposed project is expected to achieve the following outcomes:

\begin{itemize}
    \item A functional prototype system capable of detecting synthetic (AI-generated) speech in real-time from streaming audio inputs.
    \item A signal-processing and machine learning pipeline that extracts relevant speech features (e.g., MFCC, spectrogram-based representations, or SSL embeddings) for classification of real vs synthetic speech.
    \item A low-latency inference system designed to operate under VoIP-like communication conditions including codec compression, noise, and packet loss.
    \item Experimental evaluation results demonstrating system performance in terms of accuracy, robustness under degradation, and real-time processing latency.
    \item Comparative analysis of different feature extraction techniques and classification models for real-time deployment feasibility.
    \item A simulation environment for VoIP communication degradation to test system behavior under realistic network conditions.
    \item A deployable prototype (API or local application) demonstrating end-to-end detection from audio stream input to classification output.
\end{itemize}
