\subsection{Scope and Application}

The project focuses on audio-based synthetic speech detection in VoIP communication systems under real-world degraded communication conditions. The system will analyze streaming audio segments and perform near real-time inference using machine learning and signal processing techniques.

\subsubsection{Project Capabilities}

The project is capable of the following:
\begin{itemize}
    \item Detect AI-generated or synthetic speech in streaming audio
    \item Operate under degraded communication conditions
    \item Perform low-latency real-time inference
    \item Analyze robustness under various codecs and transmission distortions
    \item Provide measurable detection confidence and performance metrics
\end{itemize}


\subsubsection{Project Limitations}

The scope of this project is subject to the following limitations:
\begin{itemize}
    \item Accuracy of measurements depends on sensor quality and calibration; readings may be affected by temperature, humidity, or sensor drift
    \item Automated control is limited to compatible devices (e.g., fans, purifiers) and cannot address structural ventilation issues in buildings
    \item Designed primarily for indoor environments; may not scale effectively for large halls or industrial spaces without significant modifications
    \item Real-time monitoring and IoT features require stable internet connectivity; performance may degrade in areas with poor network access
\end{itemize}


\subsubsection{Project Applications}

The potential applications of the proposed system includes:
\begin{itemize}
    \item Voice phishing and impersonation detection
    \item Secure voice-based authentication systems
    \item Fraud prevention in telecommunication systems
    \item Online meeting and conferencing security
    \item Media authenticity verification
    \item Audio forensic analysis
\end{itemize}
